## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0.0 or higher recommended)
- `npm` (bundled with Node.js)

### Installation
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/your-username/portfolio.git
   cd portfolio
   ```

2. Install dependencies (if using external packages):
   ```bash
   npm install
   ```

### Running the Application
Start the Node.js server:
```bash
npm start
```
*Or run directly via Node:*
```bash
node server.js
```

By default, the server starts on port `3042` (or respects `PORT` environment variable):
```text
>>> Emmanuel Gyan Ansah Portfolio Server running on http://localhost:3042
```

Open your browser and navigate to:
```
http://localhost:3042
```

## 📡 REST API Documentation

The Node.js server provides built-in REST endpoints for dynamic features:

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/status` | Returns system telemetry, uptime, and active model versions. |
| `POST` | `/api/inference` | Evaluates prompt input tokens, latency, and sentiment/phenotypic probabilities. |
| `POST` | `/api/contact` | Handles transmission of recruiter and collaborator inquiries. |
| `GET` | `/api/resume` | Returns a plain-text/PDF stream of the curriculum vitae. |

#### Example Inference Request:
```bash
curl -X POST http://localhost:3042/api/inference \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Ensemble model CNN LSTM ROC-AUC 0.984", "task": "evaluate"}'
```
